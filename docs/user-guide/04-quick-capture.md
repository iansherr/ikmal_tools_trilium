# Quick Capture & Hotkey Launcher

Quick Capture lets you capture tasks, meeting notes, project hubs, and diagrams from anywhere in Trilium Notes.

---

## Accessing Quick Capture

- **Global Hotkey**: Press **`Cmd+Shift+K`** (Mac) or **`Ctrl+Shift+K`** (Windows/Linux).
- **Header Button**: Click the **Ikmal Quick Capture** icon group in Trilium's top header navigation bar.

---

## Features

1. **Template Selector**: Switch between primary templates (`Task`, `Meeting Prep`, `Story Package`, `Diagram & Whiteboard`, `Scratch Note`).
2. **Searchable Parent Pickers**: Select existing Project Hubs (`~project`) or Topic containers (`~topic`) using real-time autocomplete search.
3. **Automatic Journal Filing**: Newly captured notes are automatically linked under today's journal note when enabled.
4. **Instant Materialization**: Executes all configured If/Then automation rules and derived topic inheritance automatically upon creation.
