# Ikmal Micro-Tools Suite

Every micro-tool in **Ikmal Tools for Trilium** is declared as a standalone render note artifact. This means you can link, clone, or embed any micro-tool into project hubs, section dashboards, or daily journal templates.

---

## Catalog of Micro-Tools

1. **Ikmal Task Kanban Board** (`notes-system-kanban`)
   - Standalone Task Kanban board displaying tasks in `Todo`, `In Progress`, and `Done` columns.

2. **Ikmal Writing & Productivity Insights** (`notes-system-insights`)
   - Standalone widget rendering writing goal progress, 30-day activity heatmap, and moon phase.

3. **Ikmal Quick Capture Toolbar** (`notes-system-quick-capture`)
   - Standalone horizontal button bar for 1-click note creation directly inside project container notes.

4. **Ikmal Weather & Climate Card** (`notes-system-weather`)
   - Standalone card showing Open-Meteo local weather forecast, temperature, and daylight hours.

5. **Ikmal Time Machine (On This Day)** (`notes-system-on-this-day`)
   - Standalone widget displaying historical notes created on the exact calendar day in previous years.

6. **Ikmal Stale Note Reviewer** (`notes-system-stale-notes`)
   - Standalone widget highlighting active notes untouched for longer than the inactivity threshold.

7. **Ikmal Interactive Canvas (Beta)** (`notes-system-canvas`)
   - Standalone interactive whiteboard note for visual mind-mapping and note relationships.
